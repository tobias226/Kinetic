# KINETIC v8 — Navy / Sapphire / Ice Blue

- Verified Copley Point's public website uses a blue-led visual treatment. Used that as **inspiration**, without assuming access to official brand colour specifications or copying its logo.
- Recoloured all app components: canvas, navigation, buttons, accent linework, cards, metric tiles, tables, forms, graphs, hover/focus/expanded states, and plot labels.
- Reworked the animated `assets/kinetic-network.svg`: blues throughout the moving network, turbines, labels and light pulses; motion and geometry preserved.
- Changed `.streamlit/config.toml` for the deployed native UI and both light/dark viewer variations.
- Kept the existing workflows, fictional data, creator credit, warning disclosures and the single Explore KINETIC action.
- Added an accessible, high-contrast icy blue button with dark navy text.
- Removed previous green screenshot previews to avoid confusing old screenshots with the new appearance.

**This is a visual rebrand, not a change to the firm's or app's investment criteria.**
